# LUNA SOL · 루나솔
## EP084 실제 대본 R01 · 새로운 삼포

**제8부 「루나솔」 제4화. 선행 EP083 「거짓된 황금의 도시」.**
**마스터 R02 필수:** 브린과 에리안이 **여덟 지역의 힘을 자발적으로 나눌 수 있는 새로운 삼포 장치 자체를 완성**한다. 오스윈은 왕실이 숨겨 온 기록과 명단을 시민에게 공개한다. **완성은 장치의 제작·안전 검증 완료**이며, 여덟 지역 전체 동의나 왕도 실제 연결 성공은 EP087, 제8 맥점 복원은 EP089다.
**핵심 복선:** EP005 샘 아래 은빛 고리, EP026 여덟 표식, EP027 장인의 기록에 담긴 희생 없는 설계, EP050 원본 계약의 중단권, EP074 오스윈의 기록 공개를 실물 구조와 공개 책임으로 회수.
**출연:** 아일라, 브린, 에리안, 미라, 오스윈, 기록관, 유안, 광산·숲·항구·북방 지역 대표단(그들의 자율 참여는 지금 당장 실제 연결 승인이 아님), 니베와 녹스(비언어). 세레나 달 성역, 아우렐 잠든 채.
**미션:** M217 분산형 공방 가동 준비 / M218 여덟 독립 부품 제작과 검증 / M219 새 삼포 본체 완성·공개 기록.
**물리·윤리 제한:** 구형 삼포 중앙부 재사용 금지, EP076 손상 삼포 파편·증거 봉인 태양 렌즈 사용 금지, 강제 추출 경로/자동 부하 전가 없음. 드래곤은 원료나 조합 아이템이 아님. 사용자가 한 손 검지로 순차 선택할 수 있는 평온한 머지 설계.

# SCENE 01 · 망치는 종이를 싫어한다
**ID:** EP084_SC01

# SCENE 02 · 잘못된 중심을 비워 둔 자리
