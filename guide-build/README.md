## 6화 이후

6화 완료 저장에서 성의 생활 화면으로 이어집니다. 마을 주문, 작업대, 상점,
니베 돌보기, 방 꾸미기, 7화 서재는 플레이어가 직접 선택합니다.
7화를 열면 기존 대본의 사건을 따라 문, 열쇠, 서가를 복원합니다.
스토리 도중 성으로 돌아가 주문을 하거나, 저장하고 다시 와서 이어갈 수 있습니다.

- 공구함 에너지는 새 재료를 꺼낼 때만 사용합니다. 0이면 바로 공구함을 정리할 수 있습니다.
- 니베 돌봄 보상은 공구함을 사용한 횟수로 다시 열립니다.
- 주문과 상점은 기존 보드·보관함·저장 키를 사용합니다.
