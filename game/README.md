# LUNA SOL · 황혼의 성

브라우저에서 `game/index.html`을 열어 1화를 플레이합니다. 로컬 서버로 실행하면 저장 위치가 일정합니다. 저장소 루트에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000/game/`에 접속합니다.

1화 대본의 일곱 장면 대사를 사용합니다. 8×8 작업대에서 같은 아이템을 두 번 탭해 합성합니다. M001~M003의 복원 적용 시 해당 장소 배경이 바뀝니다. 장소 메뉴에서 복원한 공간을 다시 볼 수 있고, 진행과 보드는 브라우저에 저장됩니다.

앞마당 및 작은 방의 아이템 수량은 현재 버전의 조정값입니다. 경사로와 문서 장면은 성문 배경을 공유합니다. 정원은 1화 종료 후 둘러볼 수 있습니다. 정원 복원 후 배경은 EP010 연결용으로 포함합니다. 배경은 같은 구도의 복원 전후 WebP를 전환하는 방식입니다.
