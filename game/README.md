# LUNA SOL · 황혼의 성

저장소 루트에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000/game/`을 엽니다. 파일로 직접 여는 경우에도 같은 파일 경로와 브라우저 프로필을 사용하면 저장을 이어갈 수 있습니다. 전체화면은 브라우저 지원 범위에서 사용합니다.

## 제작 범위

- EP001~EP002의 대사와 복원 M001~M006. 원본 대본을 별도로 보관하며 대사 이후의 서사 이벤트 조건을 유지합니다.
- 첫 생활 공간에 침대와 등불이 남습니다. 의자와 탁자는 작업대에서 제작한 뒤 원하는 자리 후보에 배치합니다. 가구의 소유와 좌표를 따로 저장합니다.
- 같은 작업대를 주민 주문에도 사용합니다. 주문 보상으로 골드를 받고 창고를 확장합니다. 이야기 진행을 미뤄도 이 활동을 할 수 있습니다.
- 같은 아이템을 끌어다 놓거나 두 칸을 차례로 탭해 합칩니다. 완성품은 오른쪽 목표로 드래그하거나 선택 뒤 납품을 탭합니다. 복원 또는 제작이 완료되기 전까지 최근 납품을 회수할 수 있습니다.
- 기존 `lunasol.castle.r1`의 키를 사용하며 1화 시험판 저장을 읽습니다. 완료 저장은 작은 방으로 이어집니다. 최근 유효 저장 한 개를 추가 보존하며 본 저장을 읽지 못할 때 복구합니다.

EP003 이후, 전체 성·마을·왕국 공간, 본격적인 드래곤 돌봄, 탐험과 장기 조립은 추가 제작 범위입니다.
