## 1. 플레이의 중심과 기존 기획 판정

**작업대를 운영하면서 실제로 쓰이는 공간을 하나씩 완성한다.** 일상의 물건과 여정의 준비물은 같은 제작 체계에서 나온다. 벤치가 생기면 주민이 앉고, 공방이 돌아오면 가공과 거래가 늘고, 둥지를 손보면 드래곤이 그곳을 자기 방식으로 사용한다. 이 변화가 다음 목표다.

- **확정 제약** · 8부 90화의 사건·인물·관계·복선·상태 연속성 보존. 복원·생활·육성은 독립 운영되며 이야기와 양방향으로 연결. 드래곤 합성·강제 추출 금지. 샤오신패드 P11 가로 전체화면·오른손 검지 한 개 우선, 휴대폰 대응, 광고·과금·강제 출석·현실시간 대기·정밀 드래그 강요 금지.
- **R01에서 유지** · 지역별 시각 복원, 기존 사건·장면·미션 식별자, 머지2, 자동 저장, 주요 장소와 접근성. 90화와 30~45시간은 제작 목표이며 시뮬레이션으로 확정할 시간이 아니다.
- **R02에서 유지** · 공간의 기능·실물과 자유 복원 중심, 독립 경제·육성, 퀘스트가 제공하는 준비와 해금. R02의 세 보드는 세 제작 목적을 설명하는 제안이다. 동일 원료를 서로 다른 사용처에 배정한다는 장점과 P11 한 손 탐색 비용을 비교해 공용 보드를 추천한다.
- **조정** · 시험판 8×8과 장면마다 이어지는 고정 제작 목록을 최종 구조로 채택할 근거는 없다. 6×6을 우선 검증한다. EP001에서 생산·합성·납품·설치를 익히고, 이후는 새 기능의 문맥 안내만 한 번 제공한다. 90화의 기존 M 식별자는 추적 키이며 실제 필수 제작 수량은 별도 데이터에 둔다.

## 2. 플레이 순환과 화면

**공방 생산 → 선택한 목표에 머지·조립품 사용 → 설치/납품/돌봄 → 공간·행동·경제 변화 → 다음 재료나 기능을 선택.** 한 방문에서 자유 프로젝트 하나를 끝내거나, 진행 중인 긴 프로젝트를 한 단계만 끝내고 멈출 수 있다. 추천 활성 목표 3개는 자유 복원, 생활 작업, 이야기 준비 중 현재 할 일을 대변한다. 핀 고정과 교체로 관리하고, 미완성 목표는 게시판에 보존한다.

| 보드 안 | 보드 옆 | 다른 화면으로 나갈 때 |
|---|---|---|
| 공용 6×6 권장, 생산기 2개 시작, 중후반 권장 3~4개. 각 생산기는 한 칸 차지. 오른쪽 2열에서 우선 편성하며 사용자가 재배치 가능 | 우측 현재 납품 목표, 제작 출처, 품목별 보관함, 선택 품목의 작업 버튼. 여러 목표는 탭으로 전환하며 현재 납품처를 한 개 선택 | 전체 보드 상태 유지. 방·정원·둥지에서 실물 배치, 공방에서 조립, 지도에서 준비 상태를 본다. 독립 장식 화면은 같은 재고를 사용한다. |

| 안 | 장점 | 비용 및 추천 |
|---|---|---|
| 공용 보드 + 창고 | 목재를 가구·주문·둥지 중 어디에 쓸지 한 곳에서 판단. 목표 전환 시 새 자원 흐름이 보인다. | 계열이 늘면 혼잡하다. 하단 창고 탭, 작업 중인 것만 보드에 편성. **기본 추천.** |
| 건축·경제·육성 완전 분리 | 분야별 물품을 찾기 쉽고 화면당 작업 밀도가 낮다. | 보드·재고 이동과 학습 비용, 중복 생산기. 동일 재료가 세 화면에서 경쟁하는 상황을 이해하기 어렵다. |
| 공용 + 한시 조립 공간 | 공용 경제 유지, 큰 작업의 중간 결과를 눈으로 확인. | 조립 슬롯과 보드 사이 입력이 추가된다. 공방·선착장의 **납품 스테이징**으로 사용하고, 두 번째 머지 판은 필요성 검증 후 판단한다. |

**한 손 조작** · 드래그하면 짧은 가이드와 넓은 목표 카드 전체가 반응한다. 같은 품목 두 칸 탭, 물건 선택 후 목표 카드 탭, 가구 선택 후 넓게 강조된 자리 탭도 같은 결과를 낸다. 큰 거점 버튼은 오른쪽에 둔다. 본문 탭은 대사만 넘기고 장소·제작 전환은 명시적 버튼을 둔다. 고정 카메라와 전환 옵션, 길게 누르기 없이 설치·턴·수납 지원. 시안 비교는 P11의 실제 전체화면 뷰포트·물리 터치 영역과 편하게 닿는 범위를 측정한다. 44 CSS px은 탭 목표의 초기 하한 후보일 뿐, 손이 닿기 쉬운 크기는 실기기로 정한다. 휴대폰에서는 보드 중심, 목표/창고는 아래 시트로 이동하고 같은 저장 상태를 사용한다.

## 3. 가구 제작과 기능 있는 공간

**재료 계보는 부품까지만 머지하고, 가구는 도면에서 부품을 조립한다.** 의자 두 개가 탁자로 바뀌는 규칙은 일관성을 해친다. 예를 들어 탁자는 판재·철물, 침대는 목재·침구를 쓴다. 동일 소형 아이템은 대체 가능하되 설치 가구는 하나마다 소유 ID를 갖는다. 조립품 납품 후 방의 배치 화면에서 제자리에 설치한다.

| 공간 | 첫 설치와 후속 변화 | 실제 기능과 행동 |
|---|---|---|
| 침실 | 침대·등불 → 탁자·수납 → 침구·커튼·조명 교체 | 휴식·취향 조합. 방의 사용 가능한 자리와 희망 설치 자리가 시각적으로 표시된다. |
| 거실 | 의자·탁자 → 소품·화병·두 번째 좌석 | 방문 객이 접근 가능한 자리에 앉거나 대화한다. 탁자는 소품 위치를 연다. |
| 부엌 | 조리대·식기 선반 → 화덕·보관 | 음식 및 주문 계열, 드래곤 선호 식사 제작. 조리는 부품을 즉시 소모하는 조합이며 실제 시간 대기 없음. |
| 공방 | 작업대·도구함 → 선반·가공 설비 → 설비 특화 | 도면과 조립 슬롯, 생산기 편성/개량. 만든 주문 물품이 진열되고 주민 의뢰가 늘어난다. |
| 정원 | 길·화단·의자 → 관수·채집 구역 | 간단한 물 주기·채집, 주민 왕래, 드래곤의 선택 가능한 탐색 자리. 채집은 지역 행동이고 현실시간 리셋에 의존하지 않는다. |
| 마을·지역 | 집·길·공공시설 → 가게·광장·지역 특화 시설 | 가게는 거래, 복원한 길은 통행, 시설은 조립·주문 범위 확대. 빈번한 방문·활동이 완공을 보여 준다. |

**공간 상태** · 접근 가능 → 안전/사용 가능 → 생활 설비 확보 → 특화. 핵심 기능은 해당 시설의 유효 설치에 묶는다. 안전 시설은 지정 위치, 자유 가구는 검증된 여러 배치 후보와 방향 중 선택. 가구 옮기기/상자에 돌려놓기/교체는 상호작용 순서로 제공한다. 새 가구를 설치하기 전 기존 물건을 소모하지 않는다. 기능 필수품을 마지막으로 빼면 정지될 서비스와 현재 주문을 미리 안내하고 임시 대체를 허용한다. **이미 발생한 이야기 사건과 지역 진입 이력은 유지**하고 현재 시설 사용만 일시 제한한다.

**렌더 요구** · `공간 + 고정 카메라 + 구조 레이어 + 가구 인스턴스 + 행동 경로 + 조명 상태`. 통행을 덮는 배치는 미리보기에서 거부하고 가능한 대안을 표시한다. 주민·드래곤이 이용하는 자리는 행동 태그, 진입점과 종료점이 있다. 사용 중에는 배치 미리보기는 가능하며 적용 시 안전 자리로 이동한다. 같은 레이어가 같은 상태에서 재현되어야 하고 완료 컷신 실패와 무관하게 최종 외관이 나타나야 한다.

## 4. 머지·수급·주문·경제

- **머지2** · 두 아이템의 계보와 단계가 같고 상위 레시피가 있으며 예약 잠금이 없으면 합성. 최소 이동·선택으로 상위 아이템을 얻고, 생산기·가구·유물·드래곤은 일반 합성에서 제외한다. 희귀 장식은 요구하지 않는 보너스로 지급한다. 일반 재료와 단계별 입력 수는 [밸런스](LUNA_SOL_GAME_BALANCE_R01.md)에 둔다.
- **생산과 회복** · 기본 생산은 탭 한 번당 지정 원료 하나, 비용 0, 대기 0. 개량 생산은 작업력 충전분을 사용해 상위 반제품을 얻는다. 충전분이 소진돼도 같은 생산기에서 기본 생산 가능. 완료된 서로 다른 생활 작업의 보상이 충전량을 회복한다. 필수 출발·보호 목표를 충전량이나 골드 부족으로 잠그지 않는다.
- **보관** · 원료·부품·완성 가구의 소유와 위치를 서로 분리한다. 창고는 목록 앞에서 선택/꺼내기가 가능하며 같은 품목을 한 행으로 묶어도 수량만큼 용량을 사용한다. 생산기는 별도 목록에 수납하되 보드에 꺼낸 것만 가동된다. 고유품 보관함과 비상 1칸으로 보드·창고가 동시에 찼을 때도 이동한다. 동일 조작으로 창고·작업대·보존함을 구분하고 상태가 뒤섞이지 않게 한다.
- **주민 의뢰** · 준비 가능한 계열·레벨·시설만으로 현장 게시판이 생성된다. 기본 의뢰는 항상 1개, 주문 1~2 슬롯 추가. 주문은 매일 만료 없이 유지되며 완료·교체·시설 변경 때만 새로 생성한다. 선택적 교체는 무료이며 최근 템플릿을 제외한다. 반복 주문은 가구 납품, 소비품 꾸러미, 주민 수리, 남는 재고 수거로 다양화한다.
- **상점·공방** · 가게는 1차 제작품과 외관 선택지를 팔고 공방은 조립·개량한다. 골드는 창고 확장, 생산기 특화, 장식, 대체 구입에 소비한다. 매입/판매 가격 차와 상위 품목만 노리는 주문 반복을 확인한다. 시설 혜택은 시간당 이자 대신 새 동작·새 품목·조작 절감으로 준다. 상점은 퀘스트가 없을 때도 작동한다. 판매는 실수 방지용 확인과 가장 최근 판매 취소를 제공한다. 0골드에서도 기본 생산과 곧바로 수행 가능한 의뢰가 남는다.
- **주문 편성 예시** · 기본 슬롯에는 개방된 T1~T2만으로 만들 수 있는 의뢰를 둔다. 추가 슬롯 하나에는 시설에서 만들 수 있는 T3~T4 또는 조립품, 다음 슬롯에는 보관 중인 일반품을 활용하는 의뢰를 시도한다. 각 슬롯 생성 시 계열·레시피·시설 접근·현재 활성/최근 완료 목록을 검사한다. 후보가 없으면 먼저 같은 계열의 낮은 단계로 내리고, 기본 주문 템플릿은 적어도 두 종류에서 번갈아 순환한다. 시설이 닫혀 품목을 만들 수 없다면 이전 예약을 돌려주고 사용 가능한 후보를 제안한다. 새로고침 보상은 없으며 대본이 멈춰도 게시판 갱신은 작동한다.

**납품** · 품목을 우측 복원 카드에 드래그하거나 품목 탭 후 카드 탭. 종류, 수량, 목표 유효 여부를 먼저 확인한다. 맞으면 자재가 제거되는 대신 목표의 보류 목록으로 들어간다. 조립·복원 커밋 전에는 되찾을 수 있다. 마지막 자재가 들어와 작업을 완수하면 즉시 납품을 확정하고 공간의 변화와 다음 행동을 표시한다. 목표와 다른 품목은 원위치, 복원 상태는 유지. 자유 가구는 제작 완료와 배치 확정을 구분한다.

## 5. 드래곤의 생활과 성장

**돌봄의 결과는 가까워지며 행동이 달라지는 것**이다. 음식을 제공하지 않았다고 건강·친밀도가 떨어지거나 떠나는 일은 없다. 돌아왔을 때 친밀도는 그대로이며 드래곤은 자발적으로 쉬거나 탐색한다. 개별 거처는 둥지·급수·먹이·놀이/목욕/휴식 슬롯과 색·재질 선택을 갖는다. NPC가 같은 자리를 쓰지 않도록 거처별 공유/전용 정보를 기록한다.

| 행동 | 제작·환경 연결 | 피드백 및 선택 |
|---|---|---|
| 먹이 | 부엌에서 허용된 조합으로 준비, 접시 배치 | 냄새 맡기→수락 또는 거절→먹기. 선호는 기록하며 거절 시 음식 회수. 기본식도 유효하다. |
| 놀이 | 공·리본·낮은 발판 등 재사용 물품 | 성격에 따라 접근·쫓기·지켜보기. 한 놀이 반복보다 음식·놀이·손질 등의 다양성이 친밀도에 기여한다. |
| 목욕·손질 | 얕은 물그릇과 수건, 안전한 거처 | 반응하고 물을 털거나 몸을 피한다. 수락하지 않으면 잠시 다른 행동을 제안하거나 놀이를 끝낸다. |
| 휴식·꾸미기 | 둥지 재료·방석·조명·낮은 쉼터 | 몸을 웅크리고 쉰다. 배치 변경은 선호·행동 경로에 영향을 주며 벌점이 없다. |
| 함께 지내기 | 개별 휴식 자리를 먼저 확보, 공유 구역 선택 | 접근·흉내·서로 피하기. 드래곤 두 개체가 같은 구역에 있어도 친밀도나 소비량을 경쟁시키지 않는다. |

**상태 설계** · 개체 ID, 출현/부화/서사 각성 플래그, 생활 성장 단계, 선호, 친밀도, 이미 본 행동, 현재 기분과 자리, 놀이 종류 이력, 개별 시설 및 동의 범위를 구분한다. 기분은 최근 상호작용과 현재 활동으로 표현하며 오프라인 시간으로 악화시키지 않는다. 알→유체→성장체→성체는 개체에 맞는 생활 표현이다. 기존 8개체 중 세레나·아우렐은 고대 수호룡 상태로 등장하므로 어린 성장 사다리를 적용하지 않는다. 일반 성장체에서 낮은 놀이·새 휴식 자리·개별 일상 대화, 성체에서 서식 공간 확장을 해금한다. 세부 점수와 예외는 밸런스 초안에 기록했다.

**동의** · 거절·철회는 플레이어에게 실제 효과가 있다. 거절한 놀이·동행은 즉시 끝나고 다른 활동이나 이동 계획을 선택할 수 있다. 생활 친밀도가 높아도 핵심 사건의 동의를 자동 부여하지 않는다. 서사적 각성·맥점 참여의 대상·행동·시점은 기존 대본의 조건 그대로 확인한다. 동의가 철회되면 보상이나 마력 생산을 약속한 상태로 유지하지 않는다. 생활 친밀도에 개체 판매가·생산 수익 배율을 연결하지 않는다.

## 6. 퀘스트·탐험과 본편 연결

| 연결 방향 | 시스템 조건 | 완료가 바꾸는 것 |
|---|---|---|
| 복원 → 대면·사건 | 통로와 방문 위치가 연결되고 해당 인물·시간대 상태가 맞으면 | 발생 큐에 추가. 당장 대화할지 일상을 이어갈지 선택 |
| 사건 → 장기 준비 | 사건에서 얻은 이동 필요성·지식으로 준비 도면 사용 가능 | 부품별로 납품하고 시각적으로 조립. 중간에 돌아와도 단계가 유지됨 |
| 사건 완료 → 새 공간 | 서사 상태, 안전 조건, 지도/통행 권한의 조합 | 후속 경로·새 주문·시설·서식 공간이 열린다 |
| 자유 플레이 중 | 필수 사건이 보류되거나 대화 큐가 비어 있음 | 현재 열린 곳에서 생산·배치·주문·교감 유지 |

**탐험** · 지도에서 다음 경로와 준비물을 공개. 이동수단은 부품 장착 상태가 보이며 완성·안전·통행 조건 모두 충족 후 출발 확인. 목적지 도착 조건과 귀환 가능 경로를 분리한다. 준비 독촉 시계나 실시간 잠금은 없다. 탐험 중 발견한 자재와 도면은 귀환 후 공방과 연결된다. 이동수단이 세워지는 예시는 본편 특정 회차의 이동수단을 확정하는 내용이 아니다.

**연동 예시와 적용 범위** · 대본 식별자를 다른 용도에 재활용하지 않는다. 아래 표는 설계 검증에 사용한 접점이다. 개별 90화 구현 입력과 표현은 후속 매핑이 필요하다. EP047~055는 저장소의 R02 대본을 우선 참조한다.

| 대본 접점 | 확인된 서사 조건 | 시스템 해석 |
|---|---|---|
| EP001 / M001~M003 | 성문·현관 통로·첫 생활 공간 | 접근 선행 조건은 유지. 작업대·납품·가구 상호작용 학습 종료 |
| EP002 / M004~006 → EP006 / M013~014 | 알 발견과 환경 준비, 이후 부화·생활 시설 | 알 상태에서 둥지 준비만. 먹이·놀이·성장 행동은 부화 완료 이후 |
| EP010 / M022~024, EP020 / M043~044 | 정원 단계 복원, 두 개체를 위한 쉼터 | 정원 사용 기능과 서사적 맥점 구분. 이후 셋업은 여러 드래곤을 독립 관리 |
| EP034 / M076~077 → EP044 / M100~102 | 항구 접근·초기 시설, 후속 맥점과 통행 조건 | 하부 접근과 상부 완공을 따로 저장. 수레·배 조립 수치는 실제 이동 회차를 매핑할 때 확정 |
| EP051, EP066, EP077 | 베일과 녹스의 부화, 세레나 자발적 각성 | 개체 출현 조건별 성장 경로 사용. 시나리오 각성은 생활 경험치와 독립 |
| EP089 / M232~234 → EP090 / M235~237 | 자발적 참여와 봉인 해제, 이후 계속되는 일상 | 서사 완료 한 번만 처리. 정원·공방·치료원·일상 의뢰와 돌봄의 상설 상태 활성화 |

## 7. 구현자가 사용할 데이터와 상태

| 데이터 | 주요 필드·제약 |
|---|---|

| 아이템 인스턴스 | 고유 ID, 품목, 위치, 잠금 사유. 보드/창고/조립대/설치/제출/소모 중 한 상태만 가짐 |
| 공간·시설 | 공간 ID, 접근 단계, 시설 활성, 배치 자리, 렌더 레이어, 사용 행동, 통행 연결, 방문 조건 |

| 저장 | 스키마 버전, 리비전, 룰 버전, 상태와 처리한 보상 ID, 현재 진행 요약, 유효성 검사값, 백업 목록 |

**목표 상태** · 발견 → 준비 → 일부 제출 → 충족 → 완공. 자유 프로젝트는 중간 제출을 회수할 수 있다. 보상과 상태 변경은 동일 저장 단위에서 적용한다. 시설의 사용 가능 상태는 현재 설치 조건이고, 서사 이력은 일회성이다. **이야기 상태**는 잠김 → 발생 가능 → 보기/준비 중 → 완료, 미루기는 별도 UI 상태다. 필수 사건 간 선행 그래프를 점검하고, 경제나 목록 갱신이 서사 이벤트를 중복 발행하지 않게 한다.

**저장과 복구** · 합성·이동·배치·제출·보상까지 각각 결정 전/후 중 한 일관된 상태로 자동 저장. 날아가는 애니메이션은 저장 상태를 결정하지 않는다. 예를 들어 마지막 품목 제출 직후 종료하면 재진입 시 복원 결과가 표시되고 보상을 다시 지급하지 않는다. 버전 이동은 사본에서 확인한 뒤 전환한다. 최근 유효 리비전 3세대 가안, 수동 파일 내보내기/가져오기, 복원 미리보기, 독립 슬롯. 고유품은 일반 판매에서 제외. 타임스탬프는 백업 표시에 쓰고 기기 시계를 변경해도 육성과 경제에 영향을 주지 않는다.
