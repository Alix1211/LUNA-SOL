# LUNA SOL · 총괄 디렉터 결정 사항 R01

2026-11-27 · 검토 안건, 승인 전. 기술 구현은 후속 작업이다.

## 1. 기존 결정과 이번 검토

| 확정 기준 | 이번 선택 범위 |
|---|---|
| 개별 가구가 공간을 바꾸고 생활·경제·드래곤 육성이 독립적으로 작동 | 공간 성장의 단위, 가구 배치 자유도, 혼잡 관리를 어떻게 구현할지 |
| 대본 원본·8부 90화의 주요 사건·인물과 드래곤 상태 유지 | 어떤 원본 미션을 실제 진행 조건 또는 선택적 목표로 연결할지 |
| 개인용, 광고/과금/현실시간 강제 없음. 오른손 검지 단독, P11 가로 우선 | 보드 크기, 생산기 위치, 드래그·탭의 동등 동작, 터치 크기 |
| 드래곤을 소모하지 않으며 거절·철회를 존중 | 점수 중심 성장과 행동 발견 중심 성장의 비율 |
| 1화에서 튜토리얼 종료, 만든 물건을 복원에 가져다 쓰는 접근 | 각 목표 카드의 제출 커밋·회수 UX, 가구 조립과 설치의 경계 |

## 2. 추천안과 비교

| 우선 | 결정 | 대안과 장단점 | 추천과 검증 |
|---:|---|---|---|
| 1 | 제작 보드의 단위 | **공용**은 재료의 공통 사용을 이해하기 쉽고 혼잡이 생긴다. **3개 분리**는 찾기 쉽지만 여러 화면을 오가고 재고를 중복 관리한다. **혼합**은 도면 단위 연출에 유리하나 별도 상태가 늘어난다. | 6×6 공용, 보관함, 조립 전용 스테이징. 8×8은 비교안. P11의 도달 거리·잘못 놓은 횟수·동일 목표 완료 시간으로 결정. |
| 2 | 가구 배치 | **완전 자유**는 표현 폭이 넓지만 작은 화면의 정밀 입력·충돌·경로 처리 비용이 크다. **한 자리 고정**은 쉽지만 인테리어 선택이 사라진다. | 안전 시설은 고정, 일반 가구는 넓은 후보 자리와 방향 선택. 의자와 탁자를 두 방식으로 배치해 실제 동선·사용 행동이 달라지는지 본다. |
| 3 | 기본 생산과 작업력 | **모든 생산 무료**는 편하나 시설 성장의 조작상 변화가 줄 수 있다. **배출을 에너지로 제한**하면 관리 퍼즐은 되지만 플레이가 멈출 수 있다. | 기본 무료·즉시 수급, 개량 T2에 작업력과 골드. 충전 고갈 시 기본 플레이가 편안한지, 이중 과금처럼 느끼는지 시험하고 필요하면 개량에 한 가지 비용만 남긴다. |
| 4 | 동시에 보이는 목표 | **하나 고정**은 안내가 쉽고 반복성이 크다. **모든 목표 노출**은 일의 맥락을 잃고 우측 조작부를 채운다. | 자유 복원·생활·여정 중 2~3개를 고정하고 한 번에 활성 납품처 하나를 강조. 퀘스트를 숨긴 30분에서 선택이 남는지 확인한다. |
| 5 | 경제의 깊이 | **시설과 주문을 모두 골드로 압축**하면 단순하나 소형 주문만 반복하기 쉽다. **시세·급여·유지비**까지 넣으면 운영은 깊어지지만 방과 드래곤이 부업이 된다. | 골드 하나를 기본으로, 복합 의뢰는 도면/장식/시설 쓰임을 보상. 가격 변동·급여·유지비보다 공급선과 손동작의 효율 차이를 먼저 만든다. |
| 6 | 드래곤 성장 | **친밀도 숫자 중심**은 이해하기 쉽고 같은 상호작용 반복을 유도한다. **행동 이정표만 사용**하면 발견은 좋으나 진행이 모호하다. | 개인 거처 + 다양한 수락 행동 + 공개된 친밀도 이정표. 음식/놀이/손질 반복 위주인지 확인하고 종류별 인정 상한을 시험한다. 강제 각성이나 마력 보너스는 세계관 기준에서 제외한다. |
| 7 | 본편 진행과 장기 제작 | **기존 M 전부를 필수로 사용**하면 원본 연결은 간단하나 일상 선택이 축소된다. **사건 준비를 전부 생략**하면 이야기의 동기와 탐험의 실물이 사라진다. | 주요 사건의 실제 준비만 고정하고 나머지는 공간·의뢰에 남긴다. 복수 부품과 중간 설치가 있는 이동 준비를 한 건 검증한다. 서사 순서와 조건 충족을 분리한다. |
| 8 | 납품 및 저장의 되돌리기 | **즉시 소비**는 명확하나 잘못 제출하면 재제작이 필요하다. **항상 확인 창**을 띄우면 한 손 조작 횟수가 늘어난다. | 정확한 품목만 받는 넓은 목표 카드, 중간 제출 회수, 완공 상태·아이템·보상 동시 저장. 마지막 납품 후 종료와 복구에서 중복 지급을 검사한다. |

## 3. 승인 순서와 인계

1. **먼저 묶어서 승인** · 보드와 배치, 생산 기본권, 목표 표시에 대한 1~4번 방향. 이들이 합의되어야 하나의 흐름으로 맞출 수 있다.
2. **수치는 실험값으로 취급** · 6×6, 활성 생산기 3~4개, 창고 8/12/16, 비용과 점수는 출발값이다. 한 손 실측과 두 개의 30분 경로를 우선한다. 각 단계의 숫자를 따로 승인받아 작업을 지연시키지 않는다.
3. **본편 연결 승인** · 드래곤 성장, 생활·필수 제작 경계와 EP/SC/M의 실제 선택적·필수 처리. 이야기의 사건을 바꾸는 변경은 여기 포함하지 않는다.

### 이어서 할 때의 상태

- 완료 · 네 필수 저장소 문서와 대표 대본 접점 대조, 상용 사례 5개 조사, 시스템·상태 정의, 산술 검산, 시점별 종이 시뮬레이션.
- 보류 · 90화별 활성·해금·제작 조건 전수 매핑, 후반 콘텐츠별 조립/에셋 수량 산정, 기기별 실측 플레이, 비용 보정, 실제 구현.
- 재개 순서 · 생활이 열린 30분에서 자유 배치와 주문의 상호작용부터 검증 → 같은 저장에서 부화 전후의 독립 돌봄 검증 → 몫이 다른 복원과 이동수단 준비 비교 → 본편 이벤트 매핑. 재미가 약하면 합성 횟수보다 목표, 수급, 보상과 공간 변화의 관계를 먼저 교정한다.
