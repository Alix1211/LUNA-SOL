# LUNA SOL · 루나솔
## 장편 드래곤 판타지 머지게임 통합 설계안 R01

**문서 상태:** 초기 통합 설계안. 게임 구현 전의 기획 기준이며 확정 수치와 리소스는 이후 검수한다.  
**장르:** 스토리 중심 머지 퍼즐 · 왕국 복원 · 드래곤 육성 · 로맨스 판타지  
**원전 모티브:** 핀란드 서사시 《칼레발라》  
**플랫폼:** 안드로이드 태블릿 가로 화면 우선, 휴대폰 대응  
**목표 분량:** 본편 8부 90화, 약 30~45시간, 1회 플레이 약 20~30분  
**핵심 루프:** 머지 → 복원 → 드래곤 성장 → 드라마 → 새로운 지역

---

## 1. 작품의 정체성

태양과 달이 사라진 왕국에서 오래된 성을 물려받은 여성이 드래곤들을 깨우고, 봉인된 빛과 사람들의 운명을 되찾는 장편 판타지.

작품의 네 가지 중심 요소:

1. **달과 태양:** 세계관, 마법, 드래곤, 왕국의 역사 전체를 관통하는 주제.
2. **왕국 복원:** 플레이어가 만든 아이템으로 폐허가 실제로 변화하는 시각적 성취.
3. **인물과 드래곤의 관계:** 각자 사연이 있는 인물들의 감정, 갈등과 성장.
4. **연속 드라마:** 매화 새 사건을 만나고 다음 이야기가 궁금해지는 구성.

머지는 드라마의 진행과 왕국의 변화에 직접 연결된다. 무의미한 제작량으로 시간을 늘리지 않는다.

## 2. 세계관

### 빛이 멈춘 시대

300년 전, 루나솔 왕국은 태양룡 **아우렐**과 달의 수호룡 **세레나**가 지켰다. 장인들이 두 용의 힘을 나누어 사용하도록 만든 **삼포**는 처음에는 풍요를 가져왔다. 그러나 왕실 일부가 드래곤의 생명력을 강제로 끌어내도록 장치를 개조했다.

북방의 여왕 로우히는 수호룡을 살리기 위해 삼포의 중심부를 파괴하고 태양과 달의 마력을 봉인했다. 세계는 긴 황혼에 갇혔다. 왕국이 분열되고 많은 마을이 버려졌으며 드래곤은 전설이 되었다.

### 아일라

오래된 성을 상속받은 젊은 여성 **아일라(Aila)**는 폐허가 된 탑에서 작은 은빛 알을 발견한다. 드래곤을 돌보고 성을 되살리는 과정에서 봉인된 역사와 자신의 가문에 남겨진 약속을 발견한다.

아일라는 전생의 여왕이나 절대적인 예언의 선택자가 아니다. 자신의 선택으로 새로운 질서를 만드는 주인공이다.

### 최종 갈등

삼포를 예전처럼 복구하면 다시 드래곤을 희생시킬 위험이 있다. 여덟 지역의 맥점을 복원하고 **드래곤의 자유로운 동의와 지역 간 협력**에 기초한 새로운 마력 연결망을 만드는 것이 최종적인 해결책이다.

> 원전에서 차용하는 것은 삼포, 로우히, 해와 달이 숨겨진다는 신화적 모티브다. 아일라, 카엘 등 인물, 드래곤, 직접적인 사건 구조와 결말은 게임용 창작 설정이다.

## 3. 주요 등장인물

| 인물 | 역할 | 중심 서사 |
|---|---|---|
| 아일라 | 폐성의 상속자 | 작은 성의 주인에서 새로운 왕국의 협력자로 성장 |
| 카엘 | 몰락한 왕실 후손의 기사 | 왕실의 죄와 마르켄의 정보원이었다는 사실, 신뢰와 사랑 |
| 에리안 | 고대 문헌 연구자 | 스승 오스윈의 기록 은폐와 진실 추적 |
| 미라 | 연금술사·약초사 | 북방으로 사라진 어머니를 찾아감 |
| 브린 | 대장장이 | 삼포 제작 가문의 과오와 새로운 기술 |
| 세라 | 북방 귀족 | 로우히에 대한 충성과 양심의 갈등 |
| 이벨린 | 숲의 마녀 | 지켜 온 기록과 공개해야 할 진실 사이의 선택 |
| 로엔 | 항구의 선장 | 황금회와의 과거 거래, 선원들의 피해 |
| 로우히 | 북방의 여왕 | 수호룡을 구하려다 황혼을 만든 책임 |
| 마르켄 | 황금회 지도자 | 마력과 거래를 독점하고 개조 삼포를 되살리려 함 |
| 오스윈 | 에리안의 스승 | 위험한 역사를 감춘 선택과 이후의 책임 |

로맨스는 카엘과 아일라의 경계 → 협력 → 애정 → 배신 발견 → 결별 → 신뢰 회복 → 사랑으로 발전한다. 에리안과 세라도 독립된 관계 서사를 가진다. 연애 감정은 메인 사건을 대신하지 않으며, 관련 인물의 실제 선택과 행동에서 발생한다.

## 4. 드래곤 시스템

| 드래곤 | 속성 | 역할 |
|---|---|---|
| 루미 | 은빛·달 | 첫 드래곤, 아일라와의 애착 |
| 브리아 | 숲 | 식물과 뿌리 회복 |
| 네리아 | 물 | 해류와 바다 기록 |
| 베일 | 바람 | 숨겨진 길과 상층 공간 |
| 이그니스 | 불 | 화로와 고대 기계 가동 |
| 녹스 | 그림자 | 감춰진 글씨와 흔적 |
| 세레나 | 달의 수호룡 | 봉인과 맹세의 비밀 |
| 아우렐 | 태양의 수호룡 | 태양의 귀환과 최종 선택 |

기본 성장 표현은 **알 → 유체 → 성장체 → 성체**. 성장에 따라 실루엣, 행동, 대사, 거처, 지역 상호작용이 달라진다. 스토리상 수호룡의 각성은 개별 사건을 따른다.

**살아 있는 드래곤을 서로 합성하거나 소모하지 않는다.** 머지는 알껍질, 성장 재료, 둥지 부품, 유물과 복원 재료에 적용한다.

## 5. 본편 8부 구성

| 부 | 화수 | 핵심 사건 | 복원 지역 |
|---|---|---|---|
| 1부 황혼의 성 | 01~10 | 아일라, 루미의 부화, 기사 카엘 | 폐성, 정원 |
| 2부 은빛 숲 | 11~22 | 실종 사건과 마녀 이벨린, 숲의 오염 | 숲, 약초원 |
| 3부 황금의 대장장이 | 23~33 | 삼포 설계와 장인 가문의 과거 | 공방, 광산 |
| 4부 북풍의 항구 | 34~44 | 바다, 마력 유통, 북방행의 실마리 | 항구, 등대 |
| 5부 태양룡의 전설 | 45~56 | 아우렐의 진실, 카엘의 과거 | 태양 신전 |
| 6부 얼어붙은 왕궁 | 57~68 | 로우히의 선택과 북방의 고통 | 설원, 북방 왕궁 |
| 7부 두 개의 맹세 | 69~80 | 세레나, 자유로운 계약과 새로운 삼포 | 달의 성역 |
| 8부 루나솔 | 81~90 | 왕도의 위기, 태양과 달의 귀환 | 옛 왕도 및 왕국 |

사건은 도입, 관계 변화, 갈등 상승, 결정적인 행동과 여파를 갖는다. 모든 화가 거대한 반전을 갖지는 않으며 작은 일상과 축하도 배치한다.

### 1부 개략

01 상속받은 폐성 → 02 탑의 알 → 03 카엘 등장 → 04 어머니의 노래 → 05 샘 복원 → 06 루미 부화 → 07 서재의 삼포 → 08 카엘의 숨겨진 목적 → 09 황금회 상인 → 10 첫 맥점 복원과 은빛 숲 지도.

상세 90화 사건표, 복선·인물 관계 표는 [시나리오 마스터 R02](../story/LUNA_SOL_STORY_MASTER_R02.md) 참조.

## 6. 머지게임 시스템

### 기본 규칙과 보드

- **머지2:** 같은 등급의 동일 아이템 두 개를 합치면 상위 아이템 하나.
- **보드 제안:** 8×8, 64칸. 크기는 실제 태블릿 테스트 후 조정.
- **계보:** 품목별 5~8단계, 지역과 이야기 진행에 따라 순차 해금.
- **입력:** 두 아이템을 순서대로 탭해 합성. 드래그는 선택적인 보조 입력.
- **안전:** 중요한 유물 잠금, 판매/삭제 실수 방지, 상태 자동 저장.

### 대표 계보

| 계보 | 예시 |
|---|---|
| 식물 | 씨앗 → 새싹 → 묘목 → 마법꽃 → 달빛 화관 → 생명의 화분 |
| 광물 | 작은 광석 → 정제 광석 → 수정 조각 → 마력 결정 → 봉인 수정 |
| 건축 | 목재 조각 → 다듬은 목재 → 건축 부품 → 복원 자재 → 장인의 구조물 |
| 유물 | 낡은 파편 → 문양 조각 → 고대 문자판 → 봉인 인장 → 성역의 열쇠 |

생성기는 꽃 바구니, 광석 수레, 오래된 책상, 마법 가마솥 등. 주요 장면과 지역을 복원하면 강화되거나 새로 해금된다. 광고, 유료 재화, 강제 대기시간을 넣지 않는다.

머지 목표는 **이야기 속 인물이 실제로 필요한 물건**과 연결한다. 우물을 고쳐야 물을 얻고, 서재 자물쇠를 복원해야 책을 읽으며, 등대를 수리해야 북방 항로가 열린다. 완성 보상은 숫자뿐 아니라 변화한 장소와 다음 사건이다.

## 7. 왕국 복원

복원 상태는 지역별로 다음 네 단계다.

1. **폐허:** 위험하거나 기능이 멈춤.
2. **정리:** 잔해 제거, 통로와 토대 복구.
3. **복원:** 시설·가구·식물·주민의 생활이 돌아옴.
4. **각성:** 관련 드래곤과 사건으로 해당 지역의 빛과 마법이 회복됨.

지역: 성, 정원, 은빛 숲, 공방·광산, 항구·등대, 태양 신전, 북방 왕궁, 달의 성역, 옛 왕도. 시스템상의 여덟 맥점과 화면의 방문 지역 수는 동일하다고 가정하지 않으며 시나리오 마스터의 위치 구분을 따른다.

복원 전후의 공간 구도는 최대한 유지한다. 단순한 배경 교체 대신 길, 화단, 분수, 조명, 건물, 시민과 드래곤의 활동이 누적된다.

## 8. 드라마 진행

**도입 → 새로운 필요 → 머지·복원 → 사건·대화 → 상태 변화·보상 → 다음 단서**

- 평상시: 캐릭터 초상화 + 대화창.
- 주요 사건: 배경 기반 연출.
- 감정적 전환점: 별도의 16:9 일러스트 컷인.
- 드래곤의 부화와 성장: 별도의 축하 연출.
- 선택지: 대체로 두세 가지 반응. 호감도 및 보조 대사를 변화시키되 메인 90화의 역사적 핵심을 임의로 분기하지 않음.
- 일상 사건: 주민의 부탁, 드래곤의 작은 소동, 축제, 식사, 다툼과 화해. 반복 대사 재생을 막기 위한 본 사건 기록 필요.

### 시나리오 구조

장면 ID / 배경 / 등장인물 / 등장인물이 알고 있는 정보 / 대사 / 표정 / 컷인·음향 / 머지 조건 / 종료 조건 / 변경 상태 / 다음 장면 조건을 별도 데이터로 관리한다. 스토리를 JavaScript 실행 코드에 흩뿌리지 않는다.

## 9. 3개월 분량과 밸런스

- 90화 × 평균 25분 = **37시간 30분**의 계획상 플레이 시간.
- 한 회 평균: **드라마·대화 6분 / 머지 14분 / 복원·육성 5분**.
- 90일은 현실 시간 제한이 아닌 **90번의 플레이 세션에 대응하는 콘텐츠량**. 연속 플레이 가능.
- 각 화에 고유 사건이 반드시 존재. 억지 제작량 증가, 같은 지시를 이름만 바꾼 반복 금지.
- 한 부마다 새로운 지역·인물·드래곤·기능의 의미 있는 변화.
- 본편 이후도 자유 수집, 꾸미기, 주민 일상과 드래곤 육성 가능.

이는 실제 측정값이 아니다. 플레이 테스트에서 재료 생성·합성 횟수와 대사 템포를 조정해야 한다.

## 10. 기본 화면과 접근성

- **왕국:** 복원 공간을 탐색하고 인물·건물·드래곤 선택.
- **머지 작업대:** 보드와 현재 제작 목표.
- **드래곤 보금자리:** 소유한 드래곤, 성장과 개별 사건.
- **이야기 기록:** 지나간 장면·대사 재감상.
- **왕국 지도:** 해금 지역과 복원 진행 상태.

**조작 기준:** 태블릿 가로 우선, 오른손 검지 하나. 핀치/멀티터치 필수 기능 없음. 연타·정밀 드래그·짧은 시간제한 없음. 큰 터치 영역, 대화 자동/수동 진행, 작은 글씨 및 과도한 상시 버튼 회피.

**저장 기준:** 문플로와 완전히 다른 저장 키와 백업 경로. 에피소드, 장면, 대화 선택·열람, 보드, 창고, 인물 관계, 드래곤, 시설 복원, 인벤토리, 도감에 일관성 있는 버전 관리와 복구 기능 적용.

## 11. 아트 방향

- **풍경:** 고풍스러운 석조 성, 달빛 정원, 북방 궁전, 안개 숲, 수정 호수, 황금 신전. 서정적인 유럽 판타지.
- **인물:** 영화적 조명과 로맨스 판타지의 반실사풍. 캐릭터별 외형 기준 원화 고정.
- **드래곤:** 어린 용은 친근하게, 고대 수호룡은 아름답고 장엄하게. 성장 전후 실루엣 식별.
- **아이템:** 보드에서 축소되어도 알아보기 쉬운 선명한 형태, 투명 배경, 일관된 명암/시점.
- **공간의 연속성:** 복원 단계마다 임의로 구도와 사물의 위치를 바꾸지 않음.
