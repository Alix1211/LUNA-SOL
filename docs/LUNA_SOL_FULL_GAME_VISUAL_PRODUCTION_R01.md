# LUNA SOL · 완성형 게임 시각 설계 및 제작 기준 R01

본편 8부 90화와 엔딩 이후의 재방문까지 같은 규격으로 제작한다. 화면 설계, 배경 레이어, 아이템 계보, 저장 규칙은 본편 전체에 적용한다. 지역별 작업은 실제 게임에 들어갈 단위로 제작하고 검수한다. 스토리 마스터 R02의 사건과 해금 순서를 기준으로 하며, 이전 성문 시안은 조작과 색감 참고 자료로 활용한다.

## 1. 플레이 화면

| 화면 | 고정 배치와 필수 상태 | 본편 연결 |
|---|---|---|
| 왕국 · 지역 | 풀블리드 풍경, 상단 장소명과 지도 버튼, 공간 안의 복원 표식, 우하단 현재 목표 | 같은 장소를 재방문하면 누적된 복원 결과를 보여 준다. 새 미션은 실제 손볼 위치에 표식으로 뜬다. |
| 왕국 지도 | 9개 방문 지역, 이동 경로, 현재 위치, 지역별 복원 상태 | 다음 방문지의 해금 조건을 짧게 표시한다. 8개 맥점은 지도에서 별도 문양으로 표현한다. |
| 머지 작업대 | 좌측 8×8 보드, 우측 목표와 재료 출처, 하단 창고. 좁은 화면에서는 목표 패널을 보드 아래로 이동 | 지역마다 생성기와 필요한 물건이 바뀐다. 제작 중인 물건은 화면을 오가도 남는다. |
| 대화 | 지역 배경 위에 화자 초상화, 하단 대사창, 선택지와 진행 버튼 | 서사 컷인, 표정 전환, 대사 기록을 지원한다. 대사 출력과 미션 완료 이벤트를 분리한다. |
| 보금자리 | 드래곤별 공간, 현재 모습과 교감 행동, 성장 및 관련 기록 | 부화·성장은 상태를 바꾸며 시험하는 연출이다. 참가·철회는 드래곤의 행동으로 표현한다. |
| 기록 · 도감 | 이야기, 수집품, 인물·드래곤, 아이템 계보 탭 | 완료한 장면을 재감상하고 발견한 단계까지만 확인할 수 있다. |
| 복원 결과 | 복원 표식으로 시선을 모은 뒤 같은 자리에서 대상 레이어 전환, 다음 목표 표시 | 결과는 저장하고 연출은 최초 적용 시에만 재생한다. |

기본 작업 프레임은 가로 태블릿 1280×800(16:10)이다. 보드 8×8의 타일은 68px, 간격은 5px, 우측 패널은 320px을 시작값으로 둔다. 390px 폭에서는 보드를 전체 너비로 쓰고 목표 카드를 아래에 붙인다. 버튼은 아이콘과 짧은 한글 레이블로 의미를 읽게 한다. 상태는 색과 테두리·문양을 함께 사용한다. 화면 흔들림과 번쩍임은 줄이고 복원 애니메이션은 즉시 전환 옵션을 제공한다.

## 2. 8부·9지역 배경 제작표

각 카메라 앵글은 배경 마스터 한 장과 변화 레이어 세트로 제작한다. 폐허·정리·복원·각성은 지역 전체의 진행을 보여 주는 단계다. 각 시설은 자기 미션을 완료할 때 해당 레이어만 바뀐다. 스토리에서 요구하는 변화만 해당 회차에 배치한다.

| 부·회차 | 지역 | 필수 공간과 고정 앵글 | 복원에 따라 제작할 레이어 | 재료와 빛 |
|---|---|---|---|---|
| 1부 EP001–010 | 황혼의 성 | 성문, 앞마당, 작은 방, 서재 | 사슬·걸쇠·문짝, 통로 잔해·석판, 침대·등불, 서재 잠금장치 | 회청 석재, 낡은 참나무, 낮은 호박색 실내등 |
| 1부 EP001–010 | 성의 정원 | 뒤뜰의 나무, 정원 지하 | 가지와 새잎, 뿌리 주변, 지하 맥점과 돌아온 빛 | 축축한 흙, 이끼, 옅은 은빛 |
| 2부 EP011–022 | 은빛 숲 | 숲 입구, 병든 숲길, 은빛 숲의 기록 공간 | 안개 층, 통로, 가지와 뿌리, 숲의 맥점 | 젖은 녹색, 차분한 은청, 생기 있는 잎 |
| 3부 EP023–033 | 공방·광산 | 대장간, 광산 통로, 용광로 | 통로 지지대, 공구와 작업대, 재점화한 용광로 | 그을린 철, 구리, 불씨색 |
| 4부 EP034–044 | 북풍의 항구 | 부두, 창고, 등대 | 발판·로프, 운송 시설, 등대 렌즈와 광선 | 해풍에 닳은 목재, 청회색 바다, 등대의 황동 |
| 5부 EP045–056 | 태양 신전 | 접근로, 상층 회랑, 신전 내부 | 이동 통로, 보관 차양, 관측 장치, 빛이 닿는 지점 | 마른 석재, 모래색, 선명한 금빛 |
| 6부 EP057–068 | 북방 왕궁 | 설원 진입로, 왕궁, 치료 시설 | 눈 쌓인 통로, 난방 시설, 병동 조명과 가구 | 서리 낀 백석, 청색 그림자, 생활 공간의 따뜻한 빛 |
| 7부 EP069–080 | 달의 성역 | 성역 입구, 고대 수호룡 공간, 제단 | 잠든 공간의 빛, 조작 장치, 성역 맥점 | 진주빛 석재, 연보라와 은색 |
| 8부 EP081–090 | 옛 왕도 | 거리, 봉인실, 안전 전망길 | 통로·안전 난간, 봉인실 상태, 지평선·하늘·광원 | 황혼의 회보라에서 첫 새벽의 금빛으로 전환 |

제작 시 1920×1200 이상을 기준으로 배경을 납품한다. 원경·건축·전경·변화 물체·발광을 나눠 동선과 복원 표식을 따로 조정할 수 있게 한다. 대사창이 차지하는 하단과 우측 목표 카드 위치는 구도 단계부터 확보한다. 지역별 목록은 앵글의 최소안이며, 세부 앵글은 실제 대본의 장소 ID를 읽고 발주 전에 확정한다. 최종 구간에는 지역 재방문 시점의 하늘과 광원을 검수한다.

## 3. 머지판과 아트 계보

동일 아이템 두 개를 차례로 탭하면 두 번째 칸에서 상위 아이템이 된다. 빈 칸 탭은 이동이고 드래그도 지원한다. 목표품은 복원 버튼으로 적용할 때 소모한다. 드래곤의 동의와 주요 유물은 별도 사건과 검토 가능한 상태로 저장한다. 초반에는 중앙부터 보드 칸을 열며, 확장하면서도 타일 좌표는 유지한다.

| 묶음 | 보드 에셋 | 생성기 또는 공급 방식 | 그림에서의 구분 |
|---|---|---|---|
| 성 복원 | 철물·목재·석재·청소·침구·조명 | 낡은 공구 상자, 현장 자재 | 조각 → 가공재 → 기능이 보이는 완성품 |
| 정원·숲 | 씨앗·새싹·묘목·약초 및 꽃 | 씨앗 주머니, 채집 바구니 | 열매·잎·뿌리 실루엣으로 구분 |
| 공방·광산 | 광석·정제 광석·가공품·수리 부품 | 광석 수레, 공방 도구 | 광석의 비정형, 가공재의 평면, 완성품의 구조 |
| 항구·등대 | 로프·발판·항해 및 등대 부품 | 선박 자재와 창고 도구 | 매듭·장부·렌즈의 윤곽과 재질 차이 |
| 신전·성역 | 문양·관측 장치·보조 회로 제작품 | 수리대 또는 해당 장소의 공급 | 고대 물건은 석재와 은유리, 일반 공구와 분리 |
| 북방·왕도 | 난방·치료·통행·공급 보수 자재 | 현장 자재, 치료 시설 도구 | 눈과 밝은 배경에서도 두꺼운 중간 톤 사용 |

아이콘은 같은 3/4 시점과 좌상단 광원으로 512px 투명 PNG 마스터를 제작하고 48px 실사용 크기에서 계보를 확인한다. 생성기는 모서리 표식과 별도 실루엣을 부여한다. 중요한 물건은 잠금과 설명을 제공한다. 빈 칸, 잠김, 선택, 합성 가능, 합성 완료, 생성기, 목표품, 잠긴 유물은 보드의 공통 상태다. UI 아이콘은 이동·지도·작업대·창고·기록·복원 표식·완료·닫기부터 동일한 굵기로 정리한다.

## 4. 실제 납품 단위와 검수

| 작업 단위 | 함께 납품할 것 | 확인 기준 |
|---|---|---|
| 공통 화면 | 지역·지도·작업대·대화·보금자리·기록의 기본 및 상태별 시안, 버튼·타일·UI 아이콘 | 태블릿과 휴대폰에서 버튼과 물품 수량을 읽을 수 있다. |
| 지역 | 고정 배경, 변하는 레이어, 관련 생성기·아이템, 미션별 상태 매핑 | 작업대에서 만든 물건과 배경에 달라진 부분을 연결해 볼 수 있다. |
| 회차 | 대본 장면 ID, 사용 배경 및 레이어, 초상화·표정, 아이템 목표, 복원·해금 상태 | 저장 후 재진입, 대사 건너뛰기, 재방문에서 상태와 보상이 일관된다. |
| 드래곤 등장 | 성장·반응 PNG, 배경과 잘 맞는 크기 기준, 동의/철회의 시각 표시 | 캐릭터가 직접 행동하고, 머지 재료로 표시되는 경우가 없다. |

배경은 `assets/backgrounds/<region>/<location>/`, 머지 아이템은 `assets/merge/items/<chain>/`, 생성기는 `assets/merge/generators/`, 인터페이스는 `assets/ui/` 경로를 기준으로 한다. 기존 `assets/portraits/`와 `assets/dragons/`를 연결한다. EP·장면·미션 단위로 필요한 파일과 상태를 제작표에 기록한다. 대본에서 목표 수량이나 미션 ID가 빠진 곳은 제작표에서 보류 표시하고 근거를 확정한 뒤 연결한다.

공통 인터페이스와 1부의 성·정원은 본편 규격으로 함께 제작한다. 그다음 2–8부 지역을 같은 규격으로 연결해 테마와 자료를 확장한다. 각 부마다 첫 진입 상태, 주요 복원 직후, 다음 부 해금 후 재방문을 점검한다. 최종 검수는 90화 진행, 적용 전후 저장, 엔딩 이후 재방문까지 포함한다.
