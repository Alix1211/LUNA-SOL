# LUNA SOL · 플레이 시뮬레이션과 문제점 R01

2026-11-27 · 종이 시뮬레이션과 산술 검토. 본 표의 분·시간은 설계 구간이며 실측이 아니다. 이 문서의 가상 프로젝트와 목표 시점으로 기존 90화 사건을 추가하거나 이동시키지 않는다. W/M/S/T/F/H는 [밸런스 문서](LUNA_SOL_GAME_BALANCE_R01.md)의 계보다.

## 1. 첫 30분 · 방을 완성하는 플레이

시작 조건은 새 저장과 P11 가로 화면이다. 아래 시간은 목표 분배다. 1화의 대사 길이와 읽는 속도에 따라 30분까지 도달하는 지점은 달라진다.

| 경과 | 플레이어가 실제로 하는 일 | 결정과 보상 |
|---|---|---|
| 0~7분 | 아일라가 도착한다. 판의 일부 기능을 순차 강조한다. 철물함과 목재 더미를 탭하고, 같은 쇠조각을 합치고, 부품을 우측 성문 카드에 납품한다. | 문이 열리고 들어갈 수 있는 곳이 늘어난다. 어디서 재료가 나왔고 어떤 물건으로 통로를 열었는지 반복 설명 없이 이해한다. |
| 7~15분 | 바닥을 정리해 첫 방에 들어가고 이미 필요한 침대·조명을 설치하거나 기존 물체를 보수한다. | 납품과 실물 설치의 차이를 배운다. 첫 방이 사용 가능해진다. 1화 종료 후 기존 보드와 남은 판재가 남는다. |
| 15~22분 | 첫 자율 목표로 의자를 조립한다. 의자 조립은 W2×2, 기본 생산 4·합성 2. 자리 후보 두 곳을 비교해 창가를 고른다. | 의자 설치를 직접 확인한다. 이용 가능한 좌석이 생기면 적절한 방문자의 앉기 동작을 지원한다. 이 기능을 쓰기 위해 특정 인물이 서사보다 일찍 등장하지 않는다. |
| 22~30분 | 남는 W2를 활용해 탁자(W3+M2)를 만들거나 주문에 내고 골드를 모은다. 탁자를 먼저 택하면 그 위에 소품을 놓을 수 있다. | 아직 손대지 않은 설치 자리를 보며 다음 목표를 정한다. EP002가 발생 가능하면 이야기 열기로 표시하고, 연구 경로에서는 읽지 않고 마친다. |

**검산** · 성문의 기본 생산 6·합성 4이며 초기 쇠조각 두 개가 있으면 신규 생산은 4. 의자와 탁자의 기본 생산+합성은 각각 6·10회다. 손 속도가 느린 사람이 15분에 1화를 끝내지 못해도 기능 실패로 보지 않는다. 튜토리얼에 필요 이상으로 같은 제작을 추가하지 않는다. 가구 설치·복원 전후를 보여 주는 시간이 부족하면 초반 제작 양부터 줄인다.

## 2. 스토리 퀘스트 없이 보내는 30분

**독립 시험 상태** · 1화 이후 입문 가구·기본 공방과 상점이 열린 저장을 복제. 스토리 발생 및 진행만 비활성화한다. 생활 주문은 운영한다. 시작은 0골드, W2×1, M2×1, 보관 1/8, 활성 생산기 2개다. 아래는 대사·사건 보상·드래곤 도움 없이 완결되는 경로다.

| 경과 | 행동과 계산 | 다음 선택 |
|---|---|---|
| 0~5분 | 방에 남은 자리를 살피고 의자를 먼저 고른다. 보관한 W2 하나를 꺼내고 W1 두 개로 W2를 추가한다. 부품 둘을 조립, 벽 쪽과 창가 중 창가에 설치 | 실물도 생기고 좌석 사용 자리도 늘어난다. 남은 M2는 팔거나 탁자에 사용할 수 있다 |
| 5~10분 | 주민이 필요로 하는 W2 주문을 선택. W1 두 개 생산·한 번 합성·납품으로 8골드 | 가구와 같은 자원이라 선택에 비용이 있다. 작은 재료 하나로 즉시 판매보다 주문 보상이 크지만, 주문에 집중하면 방 변화가 늦어진다 |
| 10~16분 | 탁자를 목표에 고정. W1 네 개 생산·3회 합성으로 W3를 만들고 남겨둔 M2와 탁자를 조립. 탁자를 배치하고 의자를 옮겨 동선을 확보 | 이미 만든 의자를 버리지 않고 공간을 재편할 수 있다. 탁자에 소품 자리가 생긴다 |
| 16~24분 | W3 주문을 제작해 12골드 추가. 골드 20으로 창고 확장 24에는 4가 부족하다. 장식 후보 하나에 쓰거나 보관. 경로 예시는 저장 | 창고가 당장 필요하면 주문 하나 더, 방 변화가 더 좋으면 장식을 선택한다 |
| 24~30분 | 보드의 목재를 정리하고 다음 진열·인테리어 후보를 확인한다. 현재 방 배치와 남은 재료를 저장. 설치 전후 컷을 열어 달라진 장소를 둘러본다 | 다음 로그인 때 이어갈 선택은 장식, 창고, 다른 방이다. 이야기 없이 공간 상태와 주문 활동이 남는다 |

**이 경로의 생산량** · 신규 W1 12개, 합성 8회, 조립 2회, 가구 배치 2회, 주문 2건, 총 20골드. 수량은 각각 2+2+4+4, 1+1+3+3이다. 이것만으로 30분을 보장할 수 없다. 결정을 포함해 너무 일찍 끝나면 쓸모 있는 다른 목표와 다른 생산처가 더 중요하다. 같은 물건을 세 번 납품하게 하는 방법으로 메우지 않는다. 별도 검증으로 부화 이후 저장에서 EP 이벤트를 끄고 가구 하나 대신 쿠션을 만들어 실제 휴식·놀이를 보며 돌봄까지 독립 순환하는지 확인한다.

## 3. 3시간 · 공간 기능과 초반 드래곤

**상태 가정** · 플레이어가 침실과 공방을 이용하고 있고, 빠른 경로에서 부화 사건을 통과했을 수 있다. 도달 회차가 달라도 정상이다.

1. 초반 방에 선반을 설치해 자재를 보관한다. 주문 하나를 완료하고 창고 8→12를 선택하거나, 36골드를 모아 생산기를 개량할지 비교한다.
2. 부엌이 사용 가능해지면 음식 주문과 드래곤 기본식이 같은 계열을 쓰는 것을 본다. 식재 두 종류를 보여 주고, 초반에는 F2 조합을 이용한다. 이때 한 요청을 고정하더라도 방과 관찰 화면으로 나갈 수 있다.
3. **부화했다면** T2+H2로 둥지 쿠션을 조립해 휴식 자리에 설치하고, 식사와 놀이를 한 번씩 제공한다. 거절하면 음식이 남고 놀이만 바꾼다. 친밀도와 새 행동을 확인한다. **부화 전이라면** 둥지를 준비하거나 가구·주문을 이어간다. 알에 먹이를 주거나 n시간 경과로 자동 부화하지 않는다.
4. 주문 판매로 골드를 얻고, 개량 설비를 이미 얻었다면 충전분 하나를 어느 계열의 T2에 쓸지 결정한다. 동작 수 절감과 수납/가구 외관 사이의 소비가 이후 목표다.

**관찰점** · 부화 시점에 맞춰 돌봄 UI가 자연스럽게 보이는가. 드래곤 반응을 보기 위해 주문 처리처럼 반복 탭할 필요는 없는가. 창고와 생산기 개량 선택 차이를 다음 10분에 체감하는가.

## 4. 10시간 · 마을 복원과 이동 준비 30분

**상태 가정** · 생활·공방·기초 지역 시설이 열려 있다. 모의 경로는 탐험용 보트 또는 수레의 프레임·연결구·덮개·안전 준비를 시험하는 것이다. 특정 EP·이동수단·사건을 새로 지정하지 않는다. 해당 본편 이벤트의 지식/통행 상태를 고정하고, 준비 전후 조작을 비교한다.

| 경과 | 실제 행동 | 대체 선택과 남는 결과 |
|---|---|---|
| 0~4분 | 지도에서 이동 불가 이유와 준비 도면을 확인한다. W·M·T 생산기를 편성하고 음식 생산기는 필요할 때 꺼내기로 한다. 창고에 W3×1이 있어 안전 준비 카드에 넣는다. | 지금은 W3를 구조재 쪽에 먼저 쓰면 프레임이 빨리 보인다. 둘 다 필요하므로 합계는 같고 시각적 단계와 다음 손동작이 달라진다 |
| 4~11분 | W4×2를 만든다. 기본 경로에서 목재 16개와 합성 14회. 구조재 각각을 오른쪽 프로젝트 카드에 납품해 실제 프레임이 두 단계로 나타난다. 중간 저장 후 잠시 정원을 둘러보고 돌아올 수 있다. | 기존 자재 소비와 선반 개량 선택. 켜진 충전분을 목재에 쓰면 조작을 줄일 수 있으나 이후 철물에서 쓸 양이 줄어든다 |
| 11~17분 | 철물함에서 M4를 만든다. 8개 생산·7회 합성. 장착된 연결부를 확인하고 철물함을 보관하면 빈칸이 생긴다. | 보드가 찼을 때 조립대에 완성품을 먼저 납품하거나 창고를 사용한다. 목표 카드에서 이미 냈던 물품은 이탈해도 유지된다 |
| 17~23분 | 천 계열 T4를 만든다. 8개 생산·7회 합성. 덮개가 설치된다. 예상보다 손이 피로하면 도면을 저장하고 지금 할 수 있는 의뢰나 교감으로 전환한다. | 충전분 4를 전량 여기에 쓰면 기본 15조작이 7조작으로 줄고 12골드가 든다. 이것은 속도와 골드의 선택이다 |
| 23~27분 | 식재 계열을 꺼내 F3(4개 생산·3회 합성)을 준비하고, 처음 넣은 안전 부품과 함께 두 줄이 충족되는지 확인한다. 다른 납품처에 잘못 놓으면 자재를 잃지 않는다. | 요리는 주문에도 쓸 수 있으므로 사전에 보충할지 예비 식량 없이 준비만 끝낼지 고른다. 추가 식량은 선택이며 출발 여부는 명시한 필수품만 판단 |
| 27~30분 | 조립 완료된 이동수단을 보고, 통행·안전 조건에 체크가 있는지 확인한 뒤 출발을 선택한다. 출발 전 가구 재배치 또는 주문 정산으로 돌아갈 수 있다. | 새 지역 진입이 자연스럽게 다음 목표가 된다. 조립품은 화면에 남고 출발 보상은 한 번만 적용된다 |

**검산** · 전체 요구는 T1 환산 40·합성 34. W3를 이미 보유한 경로는 신규 생산 36·합성 31로 **67회**이며, 도면의 여섯 물품과 별도 조립·확인까지 포함해도 소요 시간은 사람마다 다르다. 조작당 4초면 67회는 약 4.5분, 8초면 약 9분밖에 되지 않는다. 그러므로 **시스템이 30분의 제작 반복을 보장한다는 뜻은 아니다.** 출발 준비를 자발적으로 30분 할 이유는 프레임·설치·현장 확인·교체·다른 목표 병행에서 온다. 관심이 15분 안에 끝나면 더 빨리 출발할 수 있어야 한다. 동일 품목 요구를 늘리거나 추첨을 도입해 시간을 맞추지 않는다.

**실패 조건** · 어느 순서로 보관·생산해도 같은 행동만 반복한다고 느끼거나, 첫 프레임이 보이기 전에 사용자가 이탈하거나, 작동 가능한 대체 목적이 보이지 않는다. 개선은 중간 조립 시 공간 변화, 기존 재고 재활용, 주 재료를 만드는 선행 시설의 효율 옵션부터 한다.

## 5. 30시간 · 넓어진 생활권의 운영

1. 여러 복원 지역 가운데 지금 작업할 두 곳을 고른다. 공방·항구·치료 시설의 활성 상태가 품목과 주문을 바꾼다. 공동 보드에는 활성 생산기 3~4개와 선택한 조립품만 올린다.
2. 후반 모델처럼 30/36칸이면 마을 보수 주문과 지역 설비 제작 중 하나를 먼저 납품해 여유 6칸을 확보한다. 11개 생산기를 모두 보여 주는 도감은 보관 화면에서 보고 실제 보드에는 올리지 않는다.
3. 한 드래곤의 새 쉬는 자리를 설치한 뒤 다른 개체를 같은 공간에 초대한다. 접근·휴식·함께 지내기 같은 반응을 관찰하고, 거절하면 방을 다시 배치하거나 간섭하지 않는다.
4. 번 골드로 12→16칸 확장, 장식, 지역 특화 중 하나를 고른다. 두 곳이 모두 완공되면 새 작업을 깊게 여는 방향이 달라지고, 이미 끝난 이야기 사건을 다시 통과할 필요가 없다.

**위험** · 골드가 반복으로 쌓이는데 사용할 곳이 없거나, 모든 지역의 프로젝트가 W4·M4 요구만 반복될 수 있다. 다음 구간에서는 부품 수·배치 방식·탐험 조건·공간 행동 가운데 달라지는 요소가 두 가지 이상 보이는지 본다. 상위 단계 요구를 올려 지출과 혼잡을 맞추지 않는다.

## 6. 본편 종료 후

플레이어가 정원과 공방 사이에서 하고 싶은 일을 고른다. 예를 들어 이전에 만든 의자를 재배치하고, 주민의 수리 의뢰 한 건을 납품하고, 공방에서 얻은 새 마감의 가구를 만들어 공간을 마무리한다. 드래곤의 취향에 맞춘 휴식 공간이나 함께 쓰는 장소를 바꾸고, 실제 행동을 확인한다. 다른 지역에서 주문 또는 수집 도면이 남아 있으면 선택해 이동한다. 엔딩은 세션의 리셋이나 일일 퀘스트 잠금이 아니다. 마지막 주요 사건이 끝난 이후에도 초기 생산기, 접근 가능한 지역, 반복 의뢰, 인테리어·돌봄 컬렉션이 같은 저장에서 이어진다.

**콘텐츠 한계** · 보유한 모든 도면을 만들고 장식·생활 행동을 다 본 플레이어에게 무한한 새 동기를 약속할 수 없다. 완료 뒤에도 재배치·주문이 기술적으로 가능하고, 그중 다시 하고 싶은 활동이 있는지를 확인한다.

## 7. 구체적인 실패 시험과 판정

| 케이스 | 재현 | 통과와 개선 |
|---|---|---|
| 보드·창고 가득, 합성 쌍 없음 | 생산기 4개, 일반품 32개, 창고 16개, 비상 슬롯 사용 상태 | 회수→최소 두 여유칸→기본 생산/합성으로 복구. 고유품 보호, 비용 차감 없음 |
| 0골드·충전 0 | 생산기 보관 상태, 주문 하나 준비, 개량 구매 불가 | 기본 생산기를 다시 꺼내 작은 의뢰 또는 복원 가능. 골드·현실 시간으로 잠기지 않음 |
| 주문 편향 | 작은 주문만 골라 10건, 중형/복합 주문 경로와 비교 | 골드/조작, 보상 다양성, 창고 구입까지 걸린 행동 차이 기록. 큰 주문이 의미 없으면 보정 |
| 마지막 부품 납품 직후 종료 | 재진입 및 이전 백업 복원 | 조립 결과와 아이템 소유 위치 일치, 보상 중복 없음 |
| 튜토리얼·알·부화 경계 | EP001 종료→EP002 이전→부화 후 저장을 따로 열기 | 부화·인물 상태 보존, 생활·복원 루프는 항상 열린 공간에서 동작 |
| 한 손 피로 | P11 가로 같은 자세에서 납품·합성·창고 전환 경로 비교 | 필수 동작 전부 한 손으로 성공, 정밀 드래그 대신 탭 경로 가능. 보드 오터치, 손을 옮긴 횟수와 실제 시간 기록 |
| 퀘스트 없는 30분 | 스토리 발생 큐 완전 정지 | 자체 선택 두 곳 이상, 실제 설치/생활 변화와 다음 세션의 목표. 즐거움은 직접 관찰 전까지 미판정 |

**후속 측정** · 테스트 전 자원 상태와 추천 목표를 동일하게 맞추고, 정답을 알려주지 않는다. UI 실수와 규칙 이해 실패를 분리해 기록한다. 시점별 산술 검토는 완료했고 재미·피로·실제 세션 길이의 실기기 검증은 남아 있다.
