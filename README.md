# LUNA SOL | 루나솔

> 장편 드래곤 판타지 · 머지 퍼즐 · 왕국 복원 · 로맨스 드라마

달과 태양이 사라진 왕국에서, 오래된 성을 상속받은 아일라가 드래곤들과 함께 빛과 사람들의 삶을 되찾는 이야기.

## 프로젝트 기준

- **목표 분량:** 본편 8부, 90화 / 하루 20~30분씩 약 3개월, 총 30~45시간
- **제작 순서:** 세계관과 전체 사건표 → 전체 장면별 대본 → 게임/머지 시스템 연결 → 아트와 구현 → 통합 테스트
- **원전 모티브:** 《칼레발라》의 삼포, 로우히, 숨겨진 태양과 달. 게임의 인물·드래곤·로맨스·주요 사건과 결말은 별도 창작.
- **핵심 루프:** 머지 → 지역/시설 복원 → 드래곤 성장 → 인물 드라마 → 새로운 지역과 목표
- **플랫폼:** Android 태블릿 가로 화면 우선, 휴대폰 대응
- **조작:** 오른손 검지 하나. 합칠 아이템 두 개를 순서대로 터치 가능. 핀치/멀티터치/시간제한 강요 없음.
- **운영:** 개인용. 광고·과금·강제 출석·현실시간 진행 제한 없음.
- **저장:** 문플로와 독립된 저장 데이터, 자동 저장과 백업/복구 필수

- 본편 90화 기준 **3화 묶음당 대표 이벤트 CG 1장, 총 30장**을 시나리오 완성 이후 별도 제작한다.

## 스토리 원칙

1. **스토리를 먼저 완결**한 뒤 게임을 스토리에 맞게 구현한다.
2. 90화의 인과관계와 결말을 유지하고, 스포일러와 인물별 지식 상태를 추적한다.
3. 인물은 현재 장면에서 아는 사실만 이야기하며, 아직 발생하지 않은 사건을 선행 언급하지 않는다.
4. 드래곤은 살아 있는 동료로, 합성해 없애는 아이템이 아니다.
5. 본편 90화가 끝나도 왕국 복원, 드래곤과의 일상, 꾸미기는 이어질 수 있다.
6. 짧은 설명과 자연스러운 대화, 복원 결과의 시각적 변화를 우선한다.
7. 대본에는 장면 ID, 배경, 등장인물, 실제 대사, 플레이 구간, 종료 조건, 상태 변경을 명시한다.
